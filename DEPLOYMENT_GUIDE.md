# Deployment guide

The current Render application is in [`SVBT/`](SVBT/). Read [`SVBT/HANDOFF.md`](SVBT/HANDOFF.md) before deployment for backup, persistent-storage, migration, and operational limitations.

The root [`render.yaml`](render.yaml) sets `rootDir: SVBT`. No deployment, DNS change, or public rollout is performed by this repository change.
